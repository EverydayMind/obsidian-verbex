## What's new

- **Related Notes is now a picture.** The current note is a circle in the middle. Notes that link to it are above it, notes it links to are below it, and similar notes are on both sides. A note linked both ways appears above and below.
- **Arrows show the direction of a link.** Arrows from the notes above meet at one point on the current note, and arrows to the notes below start from one point. An arrow that comes from a property (a frontmatter field such as `related`) takes a colour from the property name; hover over it to see the name.
- **Circle colours follow the note's type.** A circle is coloured by the note's `type` property, with one colour for each type in the vault. Notes without a type are grey.
- **Click a circle to move there.** The note opens in the same tab and the picture re-centres on it in one smooth move. Ctrl/Cmd-click opens the note and keeps the picture as it is until you go to another note.
- **What is no longer shown.** The list with snippets, paths and signal badges is gone, and so is the jump to the matching line. Hovering over a circle shows the note title.

No companion plugin changed, so no new approval is needed.
