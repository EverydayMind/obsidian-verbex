## What's new

- **Review keeps the plugin name in view.** The **Review** button on the plugin approval banner now scrolls Verbex settings to the waiting plugin's row, so its name and state stay visible above the expanded details (before, the name could be cut off for plugins that need reapproval).

Includes everything from 0.1.5: plugin approval banner, clearer answers when a plugin is not approved yet, plugin tool counts in the status view, messages that point to Tool management › Tool approval, each tool call listed once, and one blank line when appending to a note.
