## What's new

- **Faster first start after an update.** On Windows, the first start after the plugin file changes could take several seconds while antivirus real-time scanning checked the new file. The plugin is now built so that this scan is several times shorter. Later starts were already fast and are unchanged.
- **Notes can be left out of search by type.** A new setting, Search › Exclude note types, lists values of the `type` property. Notes with a listed type are not indexed and do not appear in search results, related notes or gathered context. The default is `report-style-profile`, so format profile notes, which hold long machine-readable data, no longer fill search with noise. Reading such a note directly still works.
- **Indexing no longer stops on a very long line.** A note with one extremely long line (for example several hundred thousand characters of JSON) made the local embedding model fail, and the index update stopped with "All chunks in batch failed to embed". Long lines are now cut to the chunk size, and text sent to the local model is capped.
- **Rare Chinese characters no longer break keyword statistics.** A Korean or Chinese word containing a character outside the basic plane (such as U+20000) was cut in the middle of the character, which could make a whole batch fail to be stored. Words are now cut by character.

No companion plugin changed its tools, so no new approval is needed.
