## What's new

- **Counts by two keys.** The note-counting tool (`query_notes`) takes `split_by` as a second grouping key, so questions such as "meetings per month and kind" get real counts for each pair. The result states how many notes matched and how many pairs there are; when a list property puts one note in several pairs, it says so instead of claiming the pair counts add up to the note count. With Chart Hands this gives stacked charts of your notes from counted values.
- **Charts with Chart Hands 0.12.0.** The README has a new section, "Charts and data with Chart Hands", with requests that work in the sample vault: charts from CSV files and note tables, wide and long tables, gauges, checking a chart against its data, redrawing it when the data changes, restyling it, fixing a broken chart, charts of your notes and live Dataview charts.

## Fixes

- **Notes with Windows line endings.** Replacing text in a note saved with CRLF line endings failed because the agent quotes text with LF line breaks. Verbex now matches the text first as given and then, in a note that uses CRLF, with CRLF line breaks, and writes the replacement with the note's line endings. The same applies to splitting a note with Note composer, and to appending text.
- **New files without an extension.** Asking to create `Notes/Plan` created a file without an extension, which Obsidian does not show as a note. Verbex now proposes `Notes/Plan.md` and says it added the extension. If `Notes/Plan.md` already exists, it is not overwritten; the agent is asked to use that exact path.

## Compatibility

- Settings, conversations, checkpoints and indexes are unchanged.
- `query_notes` calls without `split_by` give exactly the same result as before.
- Chart Hands 0.12.0 is the recommended version for the data and chart Skill; with an older Chart Hands, Verbex shows a notice and the earlier chart features keep working. Updating Chart Hands changes its tools, so Verbex asks you to approve it again.
