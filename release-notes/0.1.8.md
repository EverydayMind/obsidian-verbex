## What's new

- **Documents marked AI-private in HWP Hands stay private.** Verbex no longer reads a document you marked private in HWP Hands, or its index note, into the model's context: not through read tools, search, the current-file context, companion plugin tools, or saved style profiles. The model is told the document was not read and that only you can change that in HWP Hands. File names can still appear in listings.
- **A tool call written as text gets one more try.** When a model writes a tool call as plain text (for example `list_files{…}`) instead of calling the tool, Verbex now asks it once to make the real call. Verbex never runs the text itself.
- **New models pick a safer API mode.** A new model defaults to Responses only when the provider points at OpenAI itself. Other OpenAI-compatible addresses, such as OpenRouter, default to Chat Completions. Existing models are unchanged. The model dialog also offers **Add a different provider** next to **Set up this provider**.
- **Clearer help when a document cannot be read yet.** If reading a Hangul or PDF document fails while plugins are waiting for approval, the model is told which plugins are waiting so it can point you to Tool approval instead of saying it cannot be done.
- **Plugins are shown by name.** Tool management, approval dialogs, the status view, and tool cards in chat show `HWPX Exporter` instead of `md-to-hwpx`, with the id in parentheses where it helps. Built-in KORDOC tools are listed separately from the KorDoc Transform plugin.
- **Smaller fixes.** Paths in the evidence lines keep their underscores. Progress text says "step" instead of "attempt" and shows when Verbex is waiting for your approval. A file changed by the same turn is described as such. Adding a model shows a confirmation. TLS options are under **Advanced**. The approval dialog summarizes read-only and changing tools, and its buttons stay in view.

Works best with HWP Hands 0.4.7 and KorDoc Transform 4.24.65, which share the AI-private list with Verbex. Their tool definitions did not change, so no new approval is needed.
