## What's new

- **Find notes by text in Related Notes.** A new area at the bottom of the Related Notes pane lists notes whose content is like the text you type, ranked the same way as the similar notes of an open note (embedding and keyword matches combined). Clicking a result opens the note and centres the graph on it.
- **Search kept apart from the graph.** The text search sits below a separator with its own heading, so its results are not read as part of the graph. Drag the separator, or use the arrow keys on it, to change the height; the height is kept for each vault.
- **Tooltips above the circles.** The title tooltip of a circle in the graph now opens above the circle and its label, so the mouse pointer no longer covers it.

No companion plugin changed its tools, so no new approval is needed.
