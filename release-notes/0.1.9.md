## What's new

- **Settings are split into five tabs.** Get started, Tool management, Chat, Search and Advanced replace one long page. Get started shows what is still needed (a provider key, a chat model, plugin approvals, save tools) with a button that takes you there. Detailed options sit under **More settings**, and the tab bar stays in view while you scroll. Options that had no effect are no longer shown; saved values are untouched.
- **A missing API key now leads to key entry.** When the cause is a provider without a key, the chat banner, the model menu, the add-model dialog and the error dialog offer **Enter API key for {provider}**, which opens that provider, instead of **Add model**.
- **Review lands on the right plugin.** Pressing **Review** on the approval banner opens Tool management with that plugin at the top and its tools to review open. The list of changed definitions stays closed, and the position holds while the page finishes loading.
- **Confirmation dialogs use one vocabulary.** Dialogs that let the AI do something now ask a plain question ("Allow saving this document?") and answer with **Allow** or **Don't allow**; **Apply** is for reviewing note changes; **Approve** is only for plugin tools. "Working copy" and "checkpoint" are replaced by "the copy being edited" and "restore point", and technical details are folded away. What each dialog permits has not changed.
- **Exports say which template was used.** When a document is created from a template, the result shown in chat and given to the model names the template.
- **Smaller changes.** Two commands were renamed to match ("Verbex: Restore points", "Verbex: Clean up restore points"); their hotkeys are kept. Korean settings use consistent terms.

No companion plugin changed, so no new approval is needed.
