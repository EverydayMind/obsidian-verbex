## What's new

- **Fewer stopped turns with plugin tools.** Verbex limits how many vault files one chat turn may send to the model. It used to count a file again every time an earlier tool result was sent with a new request, so one plugin result that listed about a hundred source notes could stop the turn with "ReadGrant cumulative budget exceeded" after two or three requests. A file now counts once per turn. The limit itself and the byte limit are unchanged.
- **Update notice for Verbex Dataview Bridge.** If Verbex Dataview Bridge 0.1.0 is installed, Verbex recommends 0.2.0. Bridge 0.2.0 reports the correct source notes for two kinds of grouped queries, so AI-private notes stay protected, and it adds a field lookup tool that helps the agent write correct queries.

## Update your plugins

| Plugin | Version | |
|---|---|---|
| Verbex Dataview Bridge | 0.2.0 | Recommended if you use Dataview |

The other plugin versions from Verbex 0.2.0 still apply. After you update a plugin, Verbex asks you to approve it again once. Updating Verbex alone does not ask again.

## Compatibility

- Settings, conversations and indexes are unchanged. Going back to 0.2.0 is safe; only the per-turn file count works as before.
