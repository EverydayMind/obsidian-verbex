## What's new

- **Setup no longer dead-ends.** When no provider is ready, the model dialog now offers **Set up this provider** (or **Add a provider**) instead of a notice with no buttons. After you save a provider that is ready, Verbex continues to adding models.
- **Re-enabling or updating Verbex keeps companion plugins working.** A companion plugin whose registration failed no longer blocks other plugins from saving or exporting until Obsidian is reloaded.
- **Save tools are easier to find.** Messages now use the name shown in settings, **Allow Vault save tools**, and say where it is. A plugin's row tells you when its save tools are still off. The format-job notice appears only when you actually ask to reuse a document's format.
- **You can see when nothing was changed.** If the model asked for a change that was not carried out and then ended its answer, Verbex adds a short fact line saying that the call did not run and no file was changed.
- **Smaller fixes.** Reading a Hangul document is no longer counted as a change. Obsidian core plugins are no longer shown as "not installed". Temporary working files are folded away in the save approval dialog. The approval button shows how many plugins and tools it covers, and long tool descriptions wrap.

Works best with HWP Hands 0.4.6 and KorDoc Transform 4.24.64, which make their tools available for Korean requests in an English Obsidian and for English requests in a Korean one. After updating those plugins, approve them again in Verbex settings › Tool management › Tool approval.
