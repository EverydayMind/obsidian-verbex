## What's new

- **Clean up stored records from the chat window.** A new eraser button in the chat header opens a window that deletes what builds up while you use Verbex: chat history, run records, rollback points, large-document job journals and backup copies. For each kind you choose everything, or only items older than 7, 30, 90 or 180 days, and you see the number of items and the size before you confirm. Deletion is permanent. Skills, prompts, workflows, settings and search indexes are never deleted.
- **What cleanup leaves alone.** The conversation you have open, runs in progress, anything changed in the last hour, and rollback points that are not settled are kept. Items are checked again right before deletion, so anything that changed while the window was open stays.
- **Install default skills from the chat window.** On a new install, or after the skills folder was removed, the chat view shows a notice offering the default skills. It opens a window where you choose sets to install: Writing (reports, summaries, meeting minutes, polishing, yearly work summaries, and the report workflow and prompts) and Using Obsidian (Bases, Canvas, Dataview, Tasks, Templater, vault tidying, merging and splitting files, authoring skills and workflows). A third set for HWP documents, slides and charts is available in Korean. The same window is the command "Install default skills, workflows and prompts".
- **Default skills in English or Korean.** The window installs the sets in the model language by default, and you can pick the other one. Files you created or changed are never replaced; untouched files that Verbex wrote earlier are updated to the language you choose.

No companion plugin changed its tools, so no new approval is needed.
