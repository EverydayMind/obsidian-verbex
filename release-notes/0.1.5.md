## What's new

- **Plugin approval banner.** When a companion plugin (HWP Hands, Chart Hands, KorDoc Transform, HWPX Exporter) is waiting for tool approval or reapproval, the chat view now says so. **Review** opens Verbex settings at Tool management › Tool approval with that plugin expanded.
- **Clearer answers when a plugin is not approved yet.** The assistant is told which installed plugins are still waiting for approval, so it points you to the approval screen instead of saying the task is impossible.
- **Status view.** Shows how many plugin tools are active, waiting, need reapproval or are off. With the BM25-only search method, "Semantic" now reads "not used".
- **Messages point to the right place.** Error messages now name Tool management › Tool approval instead of "Plugin tools".
- **Chat.** Each tool call is listed once (it was shown twice).
- **Appending to a note** adds exactly one blank line before the new text.

Companion plugins with matching changes: HWP Hands 0.4.5 (AI tool toggles apply immediately), HWPX Exporter 0.9.24 (clearer render-capture warnings).
