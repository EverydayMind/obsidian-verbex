## What's new

Verbex 0.2.0 moves plugin-specific knowledge out of Verbex and into the plugins that do the work.

- **Skills from plugins.** A connected plugin can now ship its own Skills. Verbex shows them next to your vault Skills and uses them only while that plugin is approved. Six default Skills moved this way and are no longer installed by Verbex: HWP co-editing and HWP format reuse (HWP Hands), HWPX document creation (HWPX Exporter), data insight charts (Chart Hands), presentation decks (PPTX Hands) and web table collection (Web Hands).
- **Dataview, Tasks and Templater through Bridges.** Verbex no longer talks to these plugins directly. Install Verbex Dataview Bridge, Verbex Tasks Bridge or Verbex Templater Bridge (0.1.0) for the plugin you use. When the plugin is on and its Bridge is not, Verbex shows a notice you can close. Bases and Note Composer are core Obsidian plugins and stay built in.
- **Version notices.** When a connected plugin is older than the release this Verbex expects, Verbex says which version to install. Plugins can also hide tools they cannot run at the moment, for example when the app they control is closed.
- **Updated default Skills.** If your vault still has an unedited copy of a default Skill from an earlier release, a chat band offers the new edition. Each replacement is shown as a diff and needs your approval. Edited copies are never offered.
- **Fixes.** Input limits follow the selected model's input budget. Plugin Skills count toward the context budget before a request is sent.

## Update your plugins

Install these releases (or later) together with Verbex 0.2.0:

| Plugin | Version | |
|---|---|---|
| KorDoc Transform | 4.24.66 | Required. Older releases no longer open HWP, HWPX and PDF files for Verbex. |
| HWP Hands | 0.4.8 | Recommended |
| HWPX Exporter | 0.9.28 | Recommended |
| Chart Hands | 0.11.5 | Recommended |
| Verbex Dataview / Tasks / Templater Bridge | 0.1.0 | If you use Dataview, Tasks or Templater |

After you update a plugin, Verbex asks you to approve it again once. Updating Verbex alone does not ask again.

## Compatibility

- **Old conversations** open as before. Their Skill selections are restored, and a Skill that moved to a plugin is linked to that plugin's Skill.
- **Removed:** the `dataview_query` and `render_dataview` tools, the Dataview mention, and the Tasks API preset. A saved Tasks connector keeps working. A Workflow with a removed tool step still loads. Old `kordoc__*` tool names point the model to KorDoc Transform's tools.
- **`{{dataview_results}}` is now empty.** Use the Dataview Bridge's query tool instead.
- **Going back to 0.1.16:** settings and conversations stay readable. A default Skill you replaced with the new edition keeps the new text.
