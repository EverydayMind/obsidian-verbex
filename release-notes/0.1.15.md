## What's new

- **Data and charts set for the starter installer, in English too.** The "Install default skills, workflows and prompts" window has a new set, *Data and charts*, with a skill that turns numbers from CSV files and tables in notes into totals, comparisons and report-ready Chart Hands charts. The tools compute every number; the model chooses what to ask and interprets the result. The set is available in Korean and English and needs the Chart Hands plugin, so it is not selected by default. The Korean-only set is renamed *HWP and slides*.
- **Report workflow for the data chart skill.** The skill follows the Chart Hands 0.11 report workflow: `suggest_chart` reads the request, `eda_analyze` computes aggregates and period comparisons, `build_chart` draws the result with report styles, targets, highlights, fact lines and a source line, and `build_chart` checks its own blocks (only blocks written or edited by hand need `check_chart`).

Use Chart Hands 0.11.4 or later with this skill. No Verbex tool definition changed; Chart Hands 0.11.4 has a new tool description, so approve Chart Hands again after updating it.
