# Verbex

[English](README.md)

Verbex는 볼트를 작업 공간으로 쓰는 문서 업무용 AI 에이전트입니다. 볼트의 노트·데이터 파일·문서를 근거로 답하고, 파일을 바꿀 때는 변경 내용을 Diff로 보여 준 뒤 승인받은 것만 반영합니다.

데스크톱 전용입니다. 화면과 에이전트의 언어는 앱 언어를 따릅니다. Obsidian이 한국어면 한국어, 그 밖에는 영어입니다.

## 기능

- **볼트를 근거로 한 대화.** 평소 말로 요청합니다. 에이전트가 노트, 속성(frontmatter), 할 일, 링크, Base, CSV 파일을 찾아 읽고, 근거로 쓴 노트를 답에 밝힙니다.
- **승인 뒤 반영.** 노트 생성·수정·이동·이름 변경·삭제는 Diff 검토를 거칩니다. 반영한 변경마다 체크포인트가 남아 이전 상태로 되돌릴 수 있습니다.
- **추측이 아니라 도구가 낸 사실.** 개수 세기, 집계, 날짜 계산, 링크 점검은 결정론 도구가 계산하고 모델은 그 값을 인용합니다.
- **Skill과 Workflow.** 재사용 지침(`.verbex/Skills/<이름>/SKILL.md`)과 여러 단계 작업(`.verbex/Workflows/*.workflow.yaml`)을 볼트 안의 일반 파일로 둡니다. Skill 구조는 Claude Code skill과 호환됩니다.
- **검색.** 키워드(BM25) 검색은 설치 직후부터 동작합니다. 임베딩 검색은 선택 사항이며 설정한 공급자를 씁니다.
- **다른 플러그인의 도구.** 자매 플러그인이 내놓는 도구를 승인하면 에이전트가 쓸 수 있습니다(아래 참고). MCP 서버도 지원합니다.
- **본문 안 글쓰기.** 명령 팔레트에서 커서 위치에 이어 쓰기, 선택 영역 다시 쓰기를 실행합니다.

## 시작하기

커뮤니티 플러그인으로 설치하면 키워드(BM25) 검색을 쓸 수 있습니다. 의미 검색은 릴리스 페이지의 오프라인 팩이나 임베딩 공급자가 있어야 합니다.

1. 커뮤니티 플러그인에서 **Verbex**를 설치하고 켭니다.
2. **설정 → Verbex**의 프로바이더 구역에서 모델 공급자를 추가하고 API 키를 고르거나 새로 만듭니다(키는 Obsidian 키체인에 보관됩니다). OpenAI, Anthropic, Google Gemini, OpenRouter, Ollama, LM Studio, OpenAI 호환 엔드포인트를 지원합니다.
3. 그 공급자의 채팅 모델을 추가하고 선택합니다.
4. 명령 팔레트에서 **채팅 열기**를 실행하고 볼트에 대해 묻습니다. 예: `10월 회의록 가운데 아직 체크 안 된 할 일이 있는 것은?`

Verbex는 주로 도구 호출을 지원하는 공개 가중치 모델(Gemma 4 31B)로 개발하고 시험했습니다. 더 큰 모델도 쓸 수 있습니다. OpenRouter에서는 공개 가중치 모델을 실제로 제공하는 상위 공급자에 따라 도구 호출의 안정성이 달라집니다. 모델이 도구를 부르겠다고만 쓰고 멈추는 일이 잦으면 OpenRouter 계정의 라우팅 설정에서 상위 공급자를 제한하세요.

### 수동 설치

릴리스의 `main.js`, `manifest.json`, `styles.css`를 `.obsidian/plugins/verbex/`에 복사하고 플러그인을 켭니다.

### 오프라인 묶음(Windows x64, 선택)

릴리스마다 `verbex-<버전>-offline-windows-x64.zip`이 함께 있습니다. 같은 플러그인에, 평소에는 필요할 때 내려받는 파일(데이터베이스 런타임, 토크나이저 표)과 로컬 임베딩 런타임(Node.js, ONNX Runtime, `multilingual-e5-small` 모델)을 더한 것입니다. 인터넷이 안 되는 PC이거나 임베딩을 로컬에서 계산하려면 `.obsidian/plugins/verbex/`에 풉니다.

## 자매 플러그인

따로 설치하는 커뮤니티 플러그인입니다. 없어도 Verbex는 동작합니다. 필요한 것을 설치하고 **설정 → Verbex**의 도구 구역에서 승인합니다.

| 플러그인 | 더해지는 기능 |
| --- | --- |
| Chart Hands | CSV 분석, 노트 안 Plotly 차트 |
| KorDoc Transform | HWP·HWPX·PDF·오피스 파일 읽기 |
| HWP Hands | 한글(HWP/HWPX) 문서 열기와 편집 |
| HWPX Exporter | 노트를 HWPX로 내보내기, 기존 문서 서식 재사용 |

다른 플러그인의 도구는 그 플러그인을 승인하기 전에는 모델에 보이지 않고, 파일을 저장하는 도구는 별도 허용이 필요합니다. HWP Hands는 기본으로 읽기 도구만 내놓습니다. 편집하려면 HWP Hands 설정에서 **AI 에이전트 편집 도구 허용**(저장까지 하려면 **AI 에이전트 저장 도구 허용**)을 켜고 HWP Hands를 다시 불러온 뒤 Verbex에서 다시 승인합니다.

## 안전장치

- 볼트의 파일은 권한 확인 → 승인 → 체크포인트 → 적용 순서로만 바뀝니다. 삭제와 이동은 자동 모드에서도 항상 묻습니다.
- 반영한 변경은 체크포인트에서 되돌릴 수 있습니다.
- 공급자 API 키는 플러그인 설정 파일이 아니라 Obsidian 키체인(설정 → 키체인)에 보관하고, 실행 기록과 로그에서는 가립니다. 기기마다 키를 따로 넣어야 합니다.

## 알림

- **네트워크.** 요청과 에이전트가 고른 노트 내용은 설정한 모델 공급자에게 전송됩니다. 기본 상태에서 그 밖의 곳으로는 보내지 않으며 사용 통계 수집은 없습니다.
- **필요할 때 내려받는 파일.** 플러그인 폴더에 없으면 PGlite 데이터베이스 런타임을 `unpkg.com`에서(임베딩 데이터베이스를 처음 열 때), 토크나이저 표를 `tiktoken.pages.dev`에서(토큰 수를 처음 셀 때) 내려받습니다. 오프라인 묶음에는 둘 다 들어 있습니다.
- **YouTube.** 메시지에 YouTube 링크를 넣으면 자막을 `youtube.com`에서 가져옵니다.
- **MCP 서버.** MCP 서버를 설정하면 입력한 명령을 실행하고 그 서버와 데이터를 주고받습니다.
- **로컬 임베딩(오프라인 묶음만).** 함께 든 Node.js 런타임을 이 PC에서 자식 프로세스로 실행합니다. 데이터는 PC 밖으로 나가지 않습니다.
- **볼트 밖 파일.** 없습니다. 데이터는 볼트 안 `.verbex/`(Skill, Workflow, 체크포인트, 실행 기록, 색인)와 `.verbex_json_db/`(대화 기록)에 둡니다.
- **계정·결제.** Verbex 자체에는 없습니다. 모델 공급자는 계정과 이용 요금이 필요할 수 있습니다.

## 소스에서 빌드

Windows, Node.js 24 기준입니다.

```powershell
npm.cmd ci
npm.cmd run build   # main.js 와 dist/verbex-agent/ 를 만든다
npm.cmd run lint
```

`vendor/`에는 로컬 임베딩 런타임과 모델이 들어 있어 용량이 큽니다(약 350MB).
